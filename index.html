PiperX-LeRobot

双臂机械臂 VLA 训练、异步推理与 TensorRT 部署系统

基于 LeRobot 0.6.1 打通 AgileX PiperX 双臂的三路相机数采、14 维 state/action 接口、策略训练、RTC 推理和真机部署。项目把模型服务、动作队列、ROS bridge 安全校验和运行指标放进同一条可审计链路。

  • 复用 LeRobot 原生 PI0.5 RTC，以 action chunk 和 blending 降低同步推理停顿。
  • GPU server 与 Piper client 解耦，通过私有 Unix socket 完成版本、任务和动作契约握手。
  • 提供 prefix-cache / denoise-step TensorRT 双引擎实验后端，并对 checkpoint、processor 和数值报告做严格校验。
